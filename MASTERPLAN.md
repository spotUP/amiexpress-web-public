# AmiExpress 1:1 Parity Masterplan
Goal: deliver a production-ready, reference-board-compatible 1:1 port of AmiExpress express.e by Friday. reference-board data is the single source of truth; no fallbacks or stubs. Every task must be completed and verified against express.e behavior.

## Principles
- Match express.e exactly: states, prompts, pauses, screen clears, MCI handling, command flows, data files.
- Preserve reference-board data as-is (Conf1/Node paths, screen files). No autogenerated Conf01/BBS/empty screens.
- No stubs/TODOs; every item must be production-ready before Friday.
- Always confirm behavior in express.e (use `AmiExpress-Sources/express.e`) before changing the web port.
